# Guarantees

One row per guarantee of DESIGN.md section 2.3: the sentence of spec/PROTOCOL.md it restates, quoted word for word, and its status in the harness as it stands. tests/test_validation_guarantees.py holds this file to the spec and to validation/invariants.py: every quote must be in the spec as written, every guarantee the invariants name must have a row here and every row a guarantee, and a guarantee the invariants check may not be marked "not checked". So a spec edit that rewords one of these sentences fails that test until this file, and the oracle where it quotes the same words, follow.

The statuses:
- **checked**: an invariant checks it on every step it applies to, in the tests and in every search; no trace reached so far breaks it.
- **known (F...)**: checked, and the named open finding contradicts it: either the oracle reads that rule as the library is built (known.json's `as_built`, oracle.AS_BUILT) and without the switch the harness reports the finding where known.json records it, or, for a finding no rule answered yet, the finding showed where known.json recorded it as built: F7 under the careless scope, whose verbs do what the rules forbid and git allows, until the guard's fence refused its lease, and F4 under dealing from differing looks until the workflow's one look; none is left, and each has its regression trace under validation/traces/.
- **partly checked**: the part this step's worlds reach; the rest waits for the build step, or the fix, named.
- **not checked yet**: no local world reaches it; the live canary check named measures it.
